# Battery RUL Prediction

A comparative study of machine learning models for battery Remaining Useful Life (RUL) prediction using the NASA dataset.

## Key Finding

Linear Regression outperforms more complex models with R2 of 0.9985.

## Models

- Linear Regression
- Support Vector Regression (SVR)
- Random Forest

## Data

NASA Battery Dataset (B0005, B0006)

## Structure

- `codes/`: Python scripts for each figure
- `figures/`: Generated figures
